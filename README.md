# 🌐 Networking & Network Security Portfolio

Selamat datang di repositori portofolio jaringan saya. Repositori ini berisi kumpulan *hands-on lab*, konfigurasi perangkat Cisco (Router & Switch), simulasi *Cisco Packet Tracer*, serta analisis infrastruktur jaringan dan keamanan (*network security*).

---

## 🛠️ Ringkasan Proyek & Lab

Repositori ini terbagi menjadi beberapa modul lab interaktif:

| Folder | Judul Proyek / Lab | Fokus Utama |
| :--- | :--- | :--- |
| `01-multi-department-vlan-dhcp` | Multi-Department Network Segmentation & Centralized DHCP | VLAN Segmentation, Trunking, Centralized DHCP Server |
| `02-layer3-switch-dhcp` | Enterprise Multi-VLAN & L3 Switch DHCP Management | Multilayer Switching (SVI), Inter-VLAN Routing, L3 DHCP |
| `03-router-on-a-stick-dhcp` | Router-on-a-Stick Architecture with Router DHCP | Sub-interfaces, 802.1Q Encapsulation, Centralized Router DHCP |
| `04-vtp-ssh-management` | Enterprise Infrastructure with VTP & Secure SSH | VTP Domain, Local User Auth, Remote SSH Security |
| `05-telnet-security-analysi` | Multi-VLAN Network with Telnet & Security Analysis | In-Band Management, Plaintext Analysis, Security Hardening |
